Accessibility Features

FeatherKit components include built-in accessibility features:

  • Full keyboard navigation support
  • ARIA attributes and roles
  • Focus management
  • Screen reader compatibility
  • High contrast mode support
  • Reduced motion preferences

Try this: Use Tab to navigate between buttons and press Enter or Space to activate them.
